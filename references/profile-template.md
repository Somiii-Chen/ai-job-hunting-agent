# 经历库模板

> 首次配置时，AI 读用户的简历，按这个结构在工作区生成 `profile/profile.md`。用户也可以自己补充、修改。
>
> 原则：**只写能在面试中被追问细节的真实内容。** 这里存原始事实，不存包装过的句子。写简历和邮件时只能从这里取材，不能超出这里的内容。
>
> 记不准的数字宁可不写；拿不准的地方先问用户。
