# 常用指令

在 Codex / Claude Code 里打开这个文件夹，直接发下面这些话就行。AI 会先读 `AGENTS.md`。

## 第一次使用：把经历库建起来

```
读一下 profile/profile.template.md 和我 resumes/ 里的简历，帮我整理出 profile/profile.md。
只写简历里有、我能说清楚的真实内容。拿不准的地方列出来问我，不要自己补。
```

## 开始一轮找岗位

```
读 AGENTS.md，按规则开始今天的求职任务。
每个岗位都要实际打开链接确认还在招。
有核实过的招聘邮箱的，写好邮件存成 Mail.app 草稿；只能官网投的，整理进投递清单。
做完停下来汇报，不要发送任何邮件。
```

## 指定方向继续找

```
继续找 {{城市}} 的外企 / 创业公司，方向是 {{岗位}}，重点看应届或 1 年以内经验能投的。
```

## 平台上看到好岗位，交给 AI 接手

```
这是我在招聘平台上看到的岗位：{{链接或粘贴 JD}}
帮我分析匹配度，找公司公开的招聘邮箱。找得到就写邮件建草稿，找不到就加进官网投递清单。
```

## 审核草稿

```
列出草稿箱里所有求职草稿，核对发件人、收件人、附件是不是对应的公司。
```

## 发送（只有这种明确的话才会触发发送）

```
发送编号 1、2
```

AI 会在发送前再核对一遍收件人、主题和附件，发完去"已发送"里确认，再更新 tracker。

## 面试来了

```
{{公司}} 约我 {{时间}} 面 {{岗位}}。
根据 JD 和我的经历库，帮我准备：1 分钟自我介绍、最可能被问的问题、我的项目里哪些故事最对口、要反问的问题。
然后扮演面试官和我模拟一轮。
```
